# Python AIServer Service

The **aiserver** is a FastAPI-based microservice bundled inside the Flutter app and spawned as a subprocess at startup. It handles all LLM inference, embedding generation, PST parsing, and model management over HTTP with Bearer token authentication.

---

## Overview

| Aspect | Details |
|--------|---------|
| **Framework** | FastAPI 0.120 + Uvicorn |
| **Language** | Python 3.11–3.14 |
| **Authentication** | Bearer token per app launch (generated by Flutter) |
| **Port** | Random high port (discovered via stdout scanning) |
| **Models** | GGUF local (Gemma, Qwen3-VL), cloud passthrough (Gemini/Claude/OpenAI) |
| **Embedding** | Qwen3-VL-Embedding-2B (multimodal) |
| **PST Parsing** | pypff library |
| **Deployment** | PyInstaller binary bundled in app; runs as subprocess |

## Startup Sequence

### FastAPI App Initialization

`main.py`:

```python
app = FastAPI(
    title="My Data Studio AIServer",
    version="0.1.0",
    docs_url="/docs",
    redoc_url="/redoc",
)

@app.middleware("http")
async def auth_middleware(request: Request, call_next):
    """Validate Bearer token on all requests."""
    token = request.headers.get("Authorization", "").replace("Bearer ", "")
    if not token or token != os.getenv("AISERVER_TOKEN"):
        return JSONResponse(
            {"detail": "Unauthorized"},
            status_code=401,
        )
    return await call_next(request)

@app.on_event("startup")
async def startup():
    """Initialize models on startup."""
    state.resolve_models_base()  # Set paths from env vars
    # Don't load models yet — lazy load on first request

@app.on_event("shutdown")
async def shutdown():
    """Cleanup on shutdown."""
    if state.get_llm_instance():
        # Cleanup model instance
        pass

@app.get("/health")
async def health_check():
    return {"status": "ok"}
```

## API Routes

### Chat Completions

**Endpoint:** `POST /v1/chat/completions`

Streaming or buffered chat completion (local GGUF or cloud provider passthrough).

**Request:**

```python
class ChatCompletionRequest(BaseModel):
    model: str  # e.g., "gemma-4-12b", "gemini-2.0-flash", "claude-3.5-sonnet"
    messages: List[Dict[str, str]]  # [{"role": "user", "content": "..."}]
    stream: bool = False
    temperature: float = 0.7
    max_tokens: int = 2048
    top_p: float = 0.9
    provider_api_key: Optional[str] = None  # For cloud passthrough
```

**Response (buffered):**

```json
{
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "Here's your response..."
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 15,
    "completion_tokens": 42,
    "total_tokens": 57
  }
}
```

**Response (streaming):**

```
data: {"choices":[{"delta":{"content":"Here's"}}]}
data: {"choices":[{"delta":{"content":" your"}}]}
...
data: [DONE]
```

**Implementation (routes.py):**

```python
@app.post("/v1/chat/completions")
async def chat_completions(request: ChatCompletionRequest):
    """Handle chat completion requests."""
    
    if request.stream:
        return StreamingResponse(
            _stream_chat(request),
            media_type="text/event-stream",
        )
    
    # Buffered response
    tokens = []
    async for chunk in _stream_chat(request):
        tokens.append(chunk["choices"][0]["delta"]["content"])
    
    return {
        "choices": [{
            "message": {"role": "assistant", "content": "".join(tokens)},
            "finish_reason": "stop",
        }],
    }

async def _stream_chat(request: ChatCompletionRequest):
    """Generate chat response in streaming chunks."""
    
    # Check if another generation is in progress (single-user constraint)
    if state.active_stream_count() > 0:
        raise HTTPException(409, GENERATION_BUSY_DETAIL)
    
    # Route to local or cloud model
    if request.model in ["gemma-4-12b", ...]:  # Local models
        llm = load_local_model(request.model)
    else:  # Cloud passthrough
        llm = load_gemini_model() or load_claude_model() or ...
    
    # Stream generation
    async for chunk in llm.astream(...):
        yield {
            "choices": [{
                "delta": {"content": chunk},
                "finish_reason": None,
            }],
        }
    
    yield {"choices": [{"delta": {}, "finish_reason": "stop"}]}
```

**Response:**

```json
  }

```

**Implementation:**

```python
@app.post("/util/embedding")
async def generate_embedding(request: EmbeddingRequest):
    """Generate embeddings for text or images."""
    
    model = load_embedding_model()
    
    if request.image_bytes or request.image_base64:
        # Image embedding
        image = Image.open(io.BytesIO(request.image_bytes or ...))
        embedding = model.embed_image(image)
    else:
        # Text embedding
        embedding = model.embed_text(request.text)
    
    return {
        "embedding": embedding.tolist(),
        "model": "Qwen/Qwen3-VL-Embedding-2B",
    }
```

### PST Import

**Endpoint:** `POST /util/import/pst`

Stream-parse an Outlook PST file and emit individual email records as JSONL.

**Request:**

```python
class PstImportRequest(BaseModel):
    file_path: str
```

**Response (streaming JSONL):**

```json
{"id": "email-1", "subject": "...", "from": "...", "received": 1234567890}
{"id": "email-2", "subject": "...", "from": "...", "received": 1234567891}
...
```

**Implementation (pst_parser.py):**

```python
class PstParser:
    def __init__(self, file_path: str):
        self.pst = pypff.file()
        self.pst.open(file_path)
    
    def iter_emails(self):
        """Iterate over emails in PST file."""
        for folder in self.pst.root_folder.iter_sub_folders():
            for message in folder.iter_sub_messages():
                yield {
                    "id": uuid.uuid4().hex,
                    "subject": message.subject or "(No Subject)",
                    "from": message.sender_name,
                    "to": message.recipients,
                    "cc": message.cc_recipients,
                    "received": int(message.client_submit_time.timestamp()),
                    "body": message.plain_text_body,
                    "attachments": [...],
                }
```

### Loading Models

`model_manager.py` handles lazy loading:

```python
def load_local_model(model_id: str):
    """Load a local GGUF model (llama-cpp-python)."""
    instance = state.get_llm_instance()
    if instance:
        return instance
    
    # Find model file
    model_path = find_local_model(model_id)
    if not model_path:
        raise FileNotFoundError(f"Model {model_id} not found")
    
    # Load via llama-cpp-python
    instance = Llama(
        model_path=model_path,
        n_gpu_layers=-1,  # Offload all layers to Metal on macOS
        n_ctx=4096,
        verbose=False,
    )
    
    state.set_llm_instance(instance)
    return instance

def load_embedding_model(model_id: str = "Qwen/Qwen3-VL-Embedding-2B"):
    """Load embedding model (Transformers + VL)."""
    instance = state.get_embedding_model()
    if instance:
        return instance
    
    # Download from HuggingFace if needed
    snapshot = hf_hub_download(
        repo_id=model_id,
        filename="config.json",
    )
    
    # Load via Transformers
    processor = AutoProcessor.from_pretrained(model_id)
    model = AutoModel.from_pretrained(model_id, trust_remote_code=True)
    
    state.set_embedding_model((processor, model))
    return processor, model

def load_gemini_model(api_key: Optional[str] = None):
    """Load Gemini cloud model (LangChain wrapper)."""
    from langchain_google_genai import ChatGoogleGenerativeAI
    
    return ChatGoogleGenerativeAI(
        model="gemini-2.0-flash",
        api_key=api_key or os.getenv("GOOGLE_API_KEY"),
        temperature=0.7,
    )

# Similar loaders for Claude, OpenAI, Grok
```

```python
def stream_download_gguf(hf_repo: str, filename: str):
    """Stream download progress via SSE."""
    total_size = 0
    downloaded = 0
    
    def progress_callback(downloaded_bytes, total_bytes):
        yield {
            "status": "downloading",
            "progress": downloaded_bytes / total_bytes,
```

### Archive Handling

```python
def extract_archive(archive_path: str, extract_to: str):
    """Extract zip, tar, tgz archives."""
    if archive_path.endswith(".zip"):
        with zipfile.ZipFile(archive_path) as z:
            z.extractall(extract_to)
    elif archive_path.endswith(".tar.gz") or archive_path.endswith(".tgz"):
        with tarfile.open(archive_path, "r:gz") as t:
            t.extractall(extract_to)
    elif archive_path.endswith(".tar"):
        with tarfile.open(archive_path, "r") as t:
            t.extractall(extract_to)
```

## State Management

`state.py` manages global state with thread-safe locks:

```python
class State:
    """Global state management for aiserver."""
    
    _llm_instance = None
    _embedding_model = None
    _current_model_id = None
    _generation_lock = asyncio.Lock()
    _active_streams = set()
    
    @staticmethod
    async def get_generation_lock():
        """Get lock for exclusive generation (single user)."""
        return State._generation_lock
    
    @staticmethod
    def register_stream(stream_id: str):
        """Register an active generation stream."""
        State._active_streams.add(stream_id)
    
    @staticmethod
    def unregister_stream(stream_id: str):
        """Unregister a completed stream."""
        State._active_streams.discard(stream_id)
    
    @staticmethod
    def active_stream_count() -> int:
        """Count active generation streams."""
        return len(State._active_streams)
```

## Authentication

`auth.py` validates Bearer tokens:

```python
@app.middleware("http")
async def validate_token(request: Request, call_next):
    """Validate Bearer token on all requests."""
    if request.url.path in ["/health", "/docs", "/redoc"]:
        return await call_next(request)
    
    auth_header = request.headers.get("Authorization", "")
    token = auth_header.replace("Bearer ", "")
    
    expected_token = os.getenv("AISERVER_TOKEN")
    if not expected_token or token != expected_token:
        return JSONResponse(
            {"detail": "Unauthorized"},
            status_code=401,
        )
    
    return await call_next(request)
```
